Politique de confidentialité

Usage : application personnelle permettant à son propriétaire de copier les fichiers de son Google Drive vers un autre de ses comptes Google.

Données consultées : fichiers et métadonnées Google Drive des comptes du propriétaire, uniquement pour effectuer la copie.

Stockage : aucune donnée n'est collectée, conservée sur un serveur ou transmise à un tiers. Les jetons d'accès restent sur l'ordinateur personnel du propriétaire.

Conformité : l'utilisation des données obtenues via les API Google respecte le Règlement sur les données utilisateur des services d'API Google, y compris les exigences d'utilisation limitée.

Révocation : l'accès peut être retiré à tout moment sur myaccount.google.com/permissions.
